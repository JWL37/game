## Суть игры
3D головоломка про доставку грузов. Игрок находится на складу и должен доставлять хрупкие посылки из точки А в точку Б с помощью грузового дрона. Напрямую управлять полётом дрона нельзя - необходимо заранее планировать его маршрут, записывать действия и учитывать физику распределения веса. 
Механики:
1. Игрок сначала проходит маршрут сам в режиме записи сохраняя свои координаты, повороты и действия с кнопками каждый кадр. При запуске дрон считывает этот массив данных и в точности повторяет траекторию и тайминги игрока.
2. Посылки имеют разный вес и форму. Игрок должен вручную расставить их на платформе дрона. Если груз распределен асимметрично, дрон начинает крениться, и его реальная физическая траектория отклоняется от идеального записанного маршрута.
